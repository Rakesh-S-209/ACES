⚙ Honeyport Configuration

Change which TCP ports the PortTrap daemon listens on. Enter a comma-separated list of port numbers and click Apply. The daemon will stop its current listeners and re-bind immediately — no restart required.
⚠ Ports below 1024 require Administrator / root privileges. Port 445 is reserved by Windows (SMB service) and may fail to bind.

This control writes the new port list to the live PortTrap instance only. To persist across restarts, update ACES_HONEYPORT_LIST in .env.
